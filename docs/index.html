Release notes · October 2026 →
Mows to the edge

The outer pass rides on the line you recorded, not 20 cm inside it.

Row ends stay on the lawn

Blade-on pivot turns where no arc fits, improvised turns around obstacles.

Firmware settings, no custom build

E-stop timings, charge ceiling, speed cap and tilt — clamped by the board.

LiDAR ignore lines

Draw a line along a hedge so soft vegetation no longer stops the mow.

Home Assistant auto-discovery

A native lawn-mower card, a Mow button per area, and sensors.

Install, update, repair

Real installer modes, GNSS in its own container, fleet mowing in beta.

Already running MowgliNext? v1.5.0 changes the mainboard firmware protocol. In Settings → Updates: Update the update service, then Review update → Install, then Flash firmware when the new interface asks for it.

The mower now mows on the recorded boundary by default — if your perimeter is not drivable all the way round, read the release notes first. Installed before v1.4.0? Rerun the installer once: curl -sSL https://mowgli.garden/install.sh | bash

One command to install. One click to update.

Pick your hardware, copy the command, paste it on the mower's board. Datum, NTRIP and the receiver profile are set later in the GUI onboarding wizard.

Step 1Hardware backend

Mowgli is the supported backend. OpenMower boards and Pixhawk via MAVROS are coming soon.

Step 2Universal GNSS

Universal GNSS is the only supported direct GNSS stack. Pick the receiver family and serial link here; the receiver profile, datum and NTRIP are configured in the GUI onboarding wizard after the first start.

Step 3LiDAR

LiDAR does two jobs: it steers the robot around obstacles, and it keeps the robot localized against its own map when RTK drops out. Without it the robot runs GPS-only.

Step 4Release channel

main is the stable channel. dev pulls :dev container images and checks out the dev branch.

Your install command
  1. SSH into the mower's computer and paste the command.
  2. Open http://<mower-ip>:4006 and follow onboarding.
  3. Record your areas, press play.
  4. From then on, update from Settings → Updates.
