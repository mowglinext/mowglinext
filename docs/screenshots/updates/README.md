# Update source screenshots

These screenshots are generated by
`gui/web/tests/e2e/host-updater.spec.ts` from the fully mocked updater fixture.
They demonstrate the desktop and mobile layout for selecting a complete custom
branch deployment in Simple mode, a failed data restore, and a completed rollback
with a remaining component warning. The pre-existing-health pair shows the
explicit force acknowledgement on desktop and mobile. They are not evidence of
a hardware update.

Regenerate them with:

```sh
cd gui/web
npx playwright test host-updater.spec.ts --grep "simple mode accepts another published branch"
npx playwright test host-updater.spec.ts --grep "failed update and blocked recovery explain both causes"
npx playwright test host-updater.spec.ts --grep "component warning does not block a completed rollback"
npx playwright test host-updater.spec.ts --grep "pre-existing optional health failure needs explicit force"
```
